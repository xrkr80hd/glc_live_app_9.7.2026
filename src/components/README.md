# Components

This folder contains reusable UI components shared across pages.

## Planned Components

- `Header` — Site-wide navigation header
- `Footer` — Site-wide footer with links and social icons
- `Button` — Styled button variants
- `Card` — Content card for sermons, events, etc.
- `Hero` — Hero/banner section
- `Modal` — Dialog/modal overlay
- `VideoPlayer` — Sermon video/audio player
- `EventCard` — Event listing card
- `SermonCard` — Sermon listing card
- `GivingForm` — Online giving form

> Add component files here as the project is built out.
