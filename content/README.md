# Content

This folder holds church content assets that will be managed and uploaded over time.

## Subfolders

| Folder | Purpose |
|--------|---------|
| `sermons/` | Sermon audio files, video links, and notes PDFs |
| `events/` | Event details, flyers, and images |
| `media/` | General media: photos, graphics, logos |

## Guidelines

- Keep filenames lowercase with hyphens (e.g., `2024-01-07-new-beginnings.mp3`)
- Avoid spaces or special characters in filenames
- Organize sermons by year/series as volume grows
- Large binary files (audio, video) should be stored in cloud storage;
  only link/metadata files belong in this repository

> See `docs/CONTENT_GUIDE.md` for detailed content management instructions (coming soon).
